## 修复与计量边界

- Transformer 投影采用声明的固定 256 行计算、显式因果 mask、efficient SDPA、关闭 FP16 reduced-precision reduction。保留原权重、HF 注意力类、FP16 KV、最后位置 LM head。整段与分块共用相同设置，既有逐元素容差及质量门槛不变。
- CUDA 内核最多 256 token，但每通道输出缓冲只有 256 字节。原符号范围不变，Python 层改为最多 96 token 的安全内部段；极低概率符号和 4096-token 局部稀有分布测试逐符号通过。应用块仍是独立配置。
- 检查点同步写入，SQLite WAL/FULL 逐行提交，未完成 TTFT 编码字节持久化。运行中监控源码/数据变化，拒绝不同指纹续拼，显存峰值跨尝试保留最大值。
- 首 token CPU ID 可用后才计算重叠区间，避免后处理计入 TTFT；队列容量边界、配对维度与位打包输入校验修正。默认 status 现在查询模型的全部规模目录。

469 条测量后的最终源码仅修改注册表和状态回归测试，测量逻辑未变。固定服务器副本再次完整运行 112 项测试，较大预检和真实 TinyLlama 审计也在该副本执行。

Mistral 实测峰值为 GPU 分配 13.45GiB、分配器保留 21.78GiB、进程主存 5.73GiB。第二次尝试因容器进程环境重建而丢失退出码，三次尝试记录为 `[143, 未记录, 0]`；报告没有将未知退出归为成功。
