# TinyLlama CacheGen Three-Experiment Design

Approved scope: implement the three experiments described in the preceding chat and requested by the user. Work in the existing `mini-repro-tinyllama` worktree. Use the already-downloaded TinyLlama and bundled LongChat/bandwidth files; all commands run offline on D: WSL.

1. Quality versus transmitted size: evaluate held-out continuation NLL on bundled LongChat prefixes at configurable lengths; evaluate deterministic fact retrieval at beginning, middle, end of contexts. Compare raw FP16, packed uniform 4-bit, uniform 8-bit, and CacheGen levels 1/2/3 on identical inputs. Save per-case bytes, NLL, and QA outputs, plus aggregates. Exclude the first held-out token from NLL because a restored KV contains no saved last-context logits.
2. TTFT: pre-encode identical contexts. Transfer text, uniform-8 payload, and CacheGen payload through a locally rate-limited socket at selected bandwidths. Time transfer, reconstruction, and first-token inference separately. Exclude offline encoding, report it separately. Label this a single-host emulation, not a remote-network measurement.
3. Adaptive streaming: split a full-context KV into chunks, encode each chunk at three CacheGen levels, use the bundled bandwidth traces to choose a level or text recomputation under a per-chunk deadline. Compare with fixed levels. Report trace-derived transfer estimates, local decode/prefill time, SLO violations, and local answer checks. Label trace-derived time as an estimate; do not call it observed network TTFT.

Shared constraints: do not download or install anything; keep outputs on D:; bound context plus query/continuation by TinyLlama's 2048-token window; do not alter the original author's scripts; keep the original mini result intact; provide small-sample CLI smoke options; keep raw and baseline outputs for paired comparisons. The 22-layer level schedules are exploratory and not paper-calibrated. Failed or negative comparisons remain in results.
